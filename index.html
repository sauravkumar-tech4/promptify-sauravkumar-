Your 4-Year Roadmap

Learn fundamentals first, develop real applications next, and prepare for internships and placements before graduation.

YEAR 01 · OCT 2026 – SEP 2027

Build Your Foundation

Goal: Learn programming and become comfortable building small projects.

  • Learn C++: variables, loops, functions, arrays and OOP.
  • Learn Git, GitHub and basic terminal commands.
  • Study basic DSA, searching, sorting and time complexity.
  • Learn HTML, CSS and JavaScript fundamentals.
  • Build a portfolio, calculator and student management project.
October 2026 — C++ setup

Install a compiler, configure VS Code and write your first programs.

November 2026 — Conditions and loops

Practise if/else, switch, loops and functions. Build a number guessing game.

December 2026 — Arrays and strings

Learn arrays, strings, vectors, searching and sorting.

January 2027 — OOP and pointers

Study classes, objects, constructors, references and pointers.

February 2027 — STL and GitHub

Learn vector, map, set, stack, queue and publish your code.

March 2027 — Recursion and complexity

Understand recursion, binary search and Big-O notation.

April 2027 — HTML and CSS

Build a responsive personal portfolio website.

May 2027 — JavaScript

Learn functions, arrays, objects, DOM and events.

June 2027 — APIs

Learn fetch, JSON, async/await and error handling.

July 2027 — Education website

Create a responsive course listing website for Log Band Education.

August 2027 — Deployment

Deploy your website and document projects with README files.

September 2027 — Revision

Review C++, DSA and web fundamentals. Improve incomplete projects.

YEAR 02 · OCT 2027 – SEP 2028

Become a Full-Stack Developer

Goal: Build complete applications with a frontend, backend and database.

  • Learn React, Node.js, Express and REST APIs.
  • Learn SQL and PostgreSQL; study DBMS, OS and networking.
  • Study linked lists, stacks, queues, trees, graphs and heaps.
  • Build a course platform with accounts and an admin dashboard.
  • Deploy your projects and begin applying for internships.
YEAR 03 · OCT 2028 – SEP 2029

Gain Experience

Goal: Demonstrate that you can solve problems and contribute to real software.

  • Practise medium-level DSA and dynamic programming.
  • Apply for summer internships and student developer opportunities.
  • Learn testing, authentication, deployment and code reviews.
  • Build one production-style application with documentation.
  • Practise technical interviews and basic system design.
YEAR 04 · OCT 2029 – SEP 2030

Prepare for Placements

Goal: Turn your skills, experience and portfolio into job offers.

  • Revise DSA and practise timed coding assessments.
  • Prepare OOP, DBMS, OS, networking and SQL interview questions.
  • Practise mock interviews and project explanations.
  • Apply through campus placements, company career pages and referrals.
  • Compare fixed pay, variable pay, equity and job responsibilities.

DSA Learning Targets

Focus on understanding and revising problems, not just increasing your problem count.

Year 1

Target: 100 cumulative problems

  • Arrays and strings
  • Searching and sorting
  • Hashing basics
  • Recursion fundamentals

Year 2

Target: 200 cumulative problems

  • Linked lists and stacks
  • Trees and heaps
  • Graphs and backtracking
  • Greedy algorithms

Year 3

Target: 300 cumulative problems

  • Dynamic programming
  • Advanced graph problems
  • Mixed interview practice
  • Timed coding assessments

Year 4

Target: 350 cumulative problems

  • Revise difficult problems
  • Practise mock interviews
  • Improve speed and accuracy
  • Explain time complexity
